## 🎸 Featured project: VinylDex (EPICODE Capstone)

**Music-themed collectible card game**, with a real-time pixel art hotel, online battles,
a player-to-player market and more than 140,000 cards from over 20 card games.

- **Backend:** Java 25, Spring Boot 4.1, Spring Security + JWT, Spring Data JPA, WebSocket, Flyway (86 migrations), OpenAPI/Swagger
- **Frontend:** React 19, Vite, Three.js (React Three Fiber), Motion, iOS/Android mobile app with Capacitor
- **Quality:** 294 backend tests (JUnit 5, Spring Boot Test, JaCoCo), 147 frontend tests (Vitest, Testing Library), end-to-end tests with Playwright, CI on GitHub Actions
- **Deployment:** Docker Compose on Oracle Cloud, Caddy with HTTPS and Content-Security-Policy, automated backups

[🌐 Play now](https://vinyldex.duckdns.org) · [📖 API Docs](https://vinyldex.duckdns.org/api/docs) · [📦 Repository](https://github.com/JusTMeth25/FS0226IT--CAPSTONE)
