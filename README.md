## 🎸 Progetto in evidenza: VinylDex (Capstone EPICODE)

**Gioco di carte collezionabili a tema musicale**, con hotel in pixel art in tempo reale, battaglie online,
mercato fra giocatori e oltre 140.000 carte da più di 20 giochi di carte.

- **Backend:** Java 25, Spring Boot 4.1, Spring Security + JWT, Spring Data JPA, WebSocket, Flyway (86 migrazioni), OpenAPI/Swagger
- **Frontend:** React 19, Vite, Three.js (React Three Fiber), Motion, app mobile iOS/Android con Capacitor
- **Qualità:** 294 test backend (JUnit 5, Spring Boot Test, JaCoCo), 147 test frontend (Vitest, Testing Library), end-to-end con Playwright, CI su GitHub Actions
- **Deploy:** Docker Compose su Oracle Cloud, Caddy con HTTPS e Content-Security-Policy, backup automatici

[🌐 Gioca ora](https://vinyldex.duckdns.org) · [📖 API Docs](https://vinyldex.duckdns.org/api/docs) · [📦 Repository](https://github.com/JusTMeth25/FS0226IT--CAPSTONE)
